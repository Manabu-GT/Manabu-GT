# Hi there, I'm Manabu! 👋

### 👨‍💻 Mobile & Web Engineer

I am a software engineer based in **Sunnyvale (CA), USA**, currently specializing in Android development.
I love building UI/UX libraries that make developers' lives easier.

### 🔭 Active Open Source Projects

I am currently maintaining and improving:

* 🐛 **[DebugOverlay-Android](https://github.com/Manabu-GT/DebugOverlay-Android)**
  <br>A zero-configuration runtime diagnostics overlay for Android fully written in Kotlin + Jetpack Compose. It surfaces real-time performance metrics (CPU, memory, FPS), **Logcat**, **Network**, **UI Tree**, **Device Info**, **AppExits/Crash** logging panels, and **one-tap bug reports** — all without requiring dangerous permissions.

* 📍 **[android-mock-location-mcp](https://github.com/Manabu-GT/android-mock-location-mcp)**
  <br>MCP server for controlling Android emulator GPS location during development/testing.

### 🚧 Currently Prototyping Locally

- 🗺️ **[Chizu](https://github.com/Manabu-GT/Chizu)** *(early prototype)*  
A **Kotlin Multiplatform** mapping library for Compose with a provider-agnostic core — starting with **Google Maps** and **MapLibre** support on Android, with iOS planned.

### 🌐 Other Projects

* ⚔️ **[SamuraiTyping](https://samuraityping.com/)**
  <br>Free touch-typing for kids ages 7+. No ads, no accounts, no tracking. A fun Japanese warrior-themed app with 9 levels — from Apprentice to Legend. Built by a parent.
